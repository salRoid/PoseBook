# inbox — raw strips, never published

Codex writes generated strips here as `<slug>--<m|f>.png`, one 3:1 canvas per
movement. `npm run ingest-frames` slices each on its ink, wraps every frame as
a `currentColor` mask SVG and writes `frames/corpus/<slug>/<m|f>/frame-N.svg`,
then moves the source into `done/`.

**Nothing in this folder is in git** (see `.gitignore`), and that is
deliberate: it is ~560 MB of source PNGs, and this repo is served to Health
over jsDelivr — a heavy repo is a slow clone for every consumer. The corpus is
the published artefact; these are its working files. They are also reproducible
— every strip's exact prompt is regenerated by `npm run missing`.

Keep them locally. If you need a strip that has been lost, re-generate it from
its prompt rather than looking for it in history; it was never there.
